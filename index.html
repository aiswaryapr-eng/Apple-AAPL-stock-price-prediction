How this was built

01

Features from the raw tape

Daily OHLC and volume are converted to log-returns, log-volume, intraday range, and open-close spread, then windowed over the trailing 30 trading days — the same shape of input the original LSTM notebook used, minus the raw price levels, which trip up tree models on a 40-year uptrend.

02

Gradient-boosted regressor

A gradient boosting model predicts the next day's log-return rather than a price level, so its output stays well-behaved even far outside the training range — this is a lighter stand-in for the notebook's LSTM, chosen because this sandbox has no GPU runtime or package installs available.

03

Chronological validation

Training and test are split by date, not shuffled — the model only ever sees the past when predicting the future, and the forward forecast is generated recursively, feeding each day's prediction back in as next day's input.

Data: AAPL daily OHLCV, Dec 1980 – Jun 2022. Model outputs are illustrative and re-computed from this dataset for this platform — not investment advice, not a live feed, and not the original notebook's LSTM output (this environment can't run TensorFlow). Past performance does not predict future results.
